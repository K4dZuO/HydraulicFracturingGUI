###  КОНТРАКТ ДЛЯ АГЕНТА

#### Цель

Модифицировать существующий модуль интерполяции безразмерных кривых X–Y, реализовав адаптивную систему выбора метода интерполяции (RBF / FDA) с автоматической оценкой качества восстановления и отображением результатов в отчётах GUI.

---

### 1. Расширение архитектуры интерполяции

Агент должен:

1. Сохранить существующие методы интерполяции (RBF, регрессия).
2. Добавить **FDA-интерполятор** для работы с большими массивами кривых:

   * приведение всех кривых к общей сетке Y (log-space);
   * сглаживание;
   * функциональный PCA (FPCA);
   * восстановление кривой по ограниченному числу компонент.

---

### 2. Адаптивный выбор метода

Реализовать автоматический выбор метода на основе:

* количества доступных кривых:

  * `n_curves < N_min` → RBF;
  * `n_curves ≥ N_min` → FDA;
* (опционально) дисперсии форм кривых в пространстве X–Y.

Выбранный метод должен сохраняться как:

```python
selected_method = "RBF" | "FDA"
```

---

### 3. Оценка качества восстановления (без эталона)

Реализовать **внутреннюю оценку качества**, включающую:

* согласованность формы (отсутствие резких переломов);
* отклонение от медианной формы в FDA-пространстве;
* относительную ошибку восстановления по выбранной кривой
  (через leave-one-out или восстановление из компонент).

Метрики сохранить как:

```python
quality_metrics = {
    "relative_error": float,
    "smoothness_score": float,
    "stability_score": float
}
```

---

### 4. Интеграция с GUI и отчётами

При выполнении операции «Интерполяция» в интерфейсе:

* отобразить:

  * выбранный метод интерполяции;
  * оценку качества (в процентах);
  * альтернативный метод и его качество (для сравнения).

Пример вывода в отчёте:

```
Метод интерполяции: FDA
Оценка качества: 78%
Альтернативный метод (RBF): 64%
```

---

### 5. Совместимость и расширяемость

* Не ломать существующие вызовы GUI.
* Архитектура должна позволять добавление новых методов (e.g. hybrid FDA+RBF).
* Все результаты интерполяции должны сохраняться для последующей интерпретации параметров пласта.
