# Hydraulic Fracturing GUI - Анализ ГРП

Профессиональное приложение для анализа данных гидроразрыва пласта (ГРП) и разведки месторождений.

## Новые возможности

### Формат данных
Приложение теперь работает с данными разведки месторождений в формате:
- **Skin** - фактор скин-эффекта
- **h** - толщина пласта (м)
- **N** - количество трещин
- **W** - ширина трещины (м)
- **L** - длина трещины (м)
- **a/L** - отношение a/L
- **ElemIdx** - индекс элемента
- **X, Y** - координаты (м)
- **t** - время (ч)
- **P** - давление (атм)
- **dP** - изменение давления (атм)
- **Q** - дебит (м³/сут)

### Профессиональный интерфейс

#### Вкладка "Временные ряды"
- Построение графиков давления vs время
- Графики дебита vs время
- Производные давления и дебита
- График давление vs дебит
- Сглаживание данных
- Интерполяция пропусков
- Экспорт данных

#### Вкладка "Анализ ГРП"
- Отображение параметров скважины
- Анализ режима течения
- Вычисление индекса продуктивности
- Обнаружение переходов режимов
- Автоматическая классификация:
  - Билинейное течение
  - Линейное течение
  - Псевдорадиальное течение

#### Вкладка "Эталонные кривые"
- Построение эталонных кривых для разных режимов
- Сопоставление с реальными данными
- Log-log масштаб для профессионального анализа
- Оценка качества сопоставления (R²)

#### Вкладка "Результаты"
- Сводка всех анализов
- Экспорт отчетов
- Сохранение результатов в текстовом формате

### Аналитические функции

1. **Анализ режима течения**
   - Автоматическое определение типа течения
   - Оценка уверенности классификации
   - Определение характерного времени перехода

2. **Индекс продуктивности**
   - Расчет индекса продуктивности скважины
   - Оценка эффективности ГРП
   - Анализ влияния скин-эффекта

3. **Обнаружение переходов**
   - Автоматическое выявление смены режимов течения
   - Анализ производных для детекции изменений

4. **Эталонные кривые**
   - Генерация кривых для различных режимов
   - Сопоставление с реальными данными
   - Оценка параметров скважины

## Использование

1. Загрузите CSV файл с данными в новом формате
2. Приложение автоматически распознает параметры скважины
3. Используйте вкладки для различных видов анализа
4. Экспортируйте результаты для дальнейшего использования

## Требования

- Python 3.8+
- PySide6
- pandas
- numpy
- pyqtgraph
- scipy
- pydantic

## Установка

```bash
pip install -r requirements.txt
python main.py
```
